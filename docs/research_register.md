# First research register

The initial experiment is a development smoke test. One independent synthetic assignment has six mechanically modified cases, two scripted variants, and one deterministic trial per pair. These are not six companies or twelve independent investment forecasts.

| Hypothesis | Test | Current interpretation |
| --- | --- | --- |
| M0: the lab can preserve source-to-output lineage | Original bytes → located row → typed fact → registered operation → final claim → separate evaluator | Exercised by the clean fixture and artifact checks |
| M1: unavailable or contradictory inputs cause visible degradation | Remove the prior forecast, change share units, conflict margins, or delay source availability | Required calculation/question coverage falls; the run stays incomplete |
| M2: final prose can escape a self-reported claim inventory | Append an unsupported sentence after report assembly | Independent final-artifact scan must fail the run |
| M3: reference/time boundaries exist in tools | Attempt direct reads/searches of disallowed content, unknown/late sources, and derived-cache edits | Denied before payload return; not an OS-level locked evaluation |
| H1: report-derived methods add value beyond generic finance procedures | Compare B4 against strong B1/B2/B3 baselines on fresh real assignments | Pending real reports, a live adapter, and a declared paid budget |
| H2: inferred rules transfer across firms/time | Freeze rules before a genuinely new company or future assignment | Pending; the synthetic candidate establishes no transfer result |

## Frozen protocol

`configs/experiments/fixture_smoke.json` declares the cases, variants, metrics, critical failures, and missing-data handling. Each comparison saves its selected case list and actual caps before generating any output. Every run embeds the same protocol hash within its pair.

The generic and candidate routes share model ID, evidence source manifest, cutoff, output target, tools and caps. Actual usage is retained. The candidate adds one explicit single-driver check; the generic workflow already applies the financial comparability requirement, so a content tie is expected.

No significance tests, realized returns, recommendation matching, or automatic research-quality winner are reported. The comparison records mechanical outcomes and gaps. General-agent and direct-exemplar baselines cannot be represented by deterministic placeholders as if they were live results.

## Evaluation limits

The evaluator uses an independent rational implementation and the public synthetic oracle in `fixtures/evaluator/`. During generation those answers are not available through the adapter interface; copies are stored in `private_eval/`. Because the answers are public fixtures and were supplied in the handoff, this is not an untouched holdout.

The final-prose checker supports the bounded synthetic language contract. It checks the complete final text, including unregistered paragraphs, and flags unknown registered assertions. It does not score arbitrary natural-language entailment or claim that resolving a citation proves its support.

A future live evaluation should use a fresh, isolated generator context, a strong general-agent comparator, frozen source snapshots, explicit costs, and analyst review of a small set of concrete claim/assumption disagreements.
